# 00-导读与学习路线

> 这套笔记是《程序员的自我修养：链接、装载与库》的讲课版整理。PDF 是扫描版，不能直接提取正文，所以这里按书签目录和本书知识脉络，用大白话重新讲一遍。目标不是背概念，而是让你能把“一个 C/C++ 程序怎么从源码跑起来”这条链路讲清楚。

## 这本书到底在讲什么

你平时写一个 `hello.c`，敲一条命令：

```bash
gcc hello.c -o hello
```

然后程序就能运行。表面看就一步，实际上背后发生了一整套流水线：

1. 预处理：把头文件、宏、条件编译这些东西先展开。
2. 编译：把 C/C++ 代码翻译成汇编。
3. 汇编：把汇编翻译成机器指令，放进目标文件。
4. 静态链接：把多个 `.o`、静态库、启动代码拼成可执行文件。
5. 装载：操作系统把可执行文件映射到进程的虚拟地址空间。
6. 动态链接：动态链接器把共享库加载进来，修正函数和变量地址。
7. 运行库初始化：在 `main` 之前准备堆、栈、I/O、全局对象等环境。
8. 系统调用：程序真正访问文件、屏幕、网络、进程等资源时，需要通过内核。

所以这本书不是单讲“链接器”，而是在讲程序运行的完整地下通道。

## 你应该抓住哪条主线

最重要的主线是：

```text
源码 -> 目标文件 -> 可执行文件 -> 进程 -> main -> 系统调用
```

每一段都有一个问题：

- 源码怎么变成目标文件？看第 2 章。
- 目标文件里到底装了什么？看第 3 章。
- 很多个目标文件怎么拼起来？看第 4 章。
- 可执行文件怎么被操作系统放进内存？看第 6 章。
- 为什么动态库可以大家共享？看第 7-9 章。
- `main` 之前和之后是谁在干活？看第 10-13 章。

## 读这本书前要先放下几个误解

### 误解 1：程序从 main 开始

不是。`main` 是你写的业务入口，但不是进程最早执行的地方。真正入口通常是运行库提供的启动代码，例如 `_start` 或 Windows CRT 入口。它先做初始化，再调用你的 `main`。

### 误解 2：编译就是生成 exe

不准确。编译只是其中一步。严格拆开看，预处理、编译、汇编、链接是不同阶段。很多“编译报错”和“链接报错”本质完全不同。

### 误解 3：库只是代码复用

库当然能复用代码，但从底层看，库还涉及符号解析、地址重定位、ABI、版本兼容、动态装载、导入导出表等一堆问题。

### 误解 4：指针就是物理内存地址

通常不是。你在程序里看到的地址一般是虚拟地址。操作系统通过页表把虚拟地址翻译到物理内存，进程之间互相隔离。

## 这套讲课版怎么读

建议顺序如下：

1. 先读 `01-温故而知新.md`，把操作系统、虚拟内存、线程这些基础补齐。
2. 再读 `02-编译和链接.md` 到 `04-静态链接.md`，把静态链接主线打通。
3. 读 `06-可执行文件的装载与进程.md` 和 `07-动态链接.md`，理解程序怎么被装进内存。
4. 读 `10-内存.md` 到 `13-运行库实现.md`，理解 `main` 前后发生什么。
5. Windows 相关内容读 `05-Windows-PE-COFF.md` 和 `09-Windows下的动态链接.md`。

## 最后先记住一句话

这本书真正想让你明白的是：你写的 C/C++ 代码只是冰山上面的一点点，下面还有编译器、链接器、装载器、动态链接器、运行库和操作系统一起托着它。理解这些东西之后，你再看链接错误、段错误、动态库加载失败、符号冲突、ABI 不兼容，就不会只觉得“玄学”了。
