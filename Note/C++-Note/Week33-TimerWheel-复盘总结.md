# Week33 TimerWheel 复盘总结

## 核心目标

Week33 实现定时器轮和精确定时器，用于连接空闲超时和心跳检测。

## 时间轮

时间轮把未来时间切成多个 slot，每次 tick 前进一格。连接注册超时时间后放入对应 slot，tick 到达时触发回调。

优点：

- 添加和刷新成本低。
- 适合大量连接的粗粒度超时。

缺点：

- 精度受 tick 粒度影响。
- 需要处理刷新后的旧 timer 记录。

## 精确定时器

最小堆适合精确 deadline：堆顶永远是最早过期任务。它比时间轮更精确，但大量连接频繁刷新时成本更高。

## 复盘结论

高性能网络库通常会同时使用粗粒度时间轮和精确定时器。连接 idle timeout 适合时间轮，少量精确任务适合最小堆。
