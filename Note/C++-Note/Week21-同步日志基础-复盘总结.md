# Week21 同步日志基础复盘总结

## 核心目标

Week21 完成同步日志系统骨架：日志级别、格式化、流式接口和线程安全写入。

## 关键设计

同步 logger 的调用链很直接：业务线程构造日志行，析构时格式化并写入 sink。它的好处是实现简单、失败路径清晰；缺点是锁和 IO 都在业务线程路径上。

## 已实现能力

- `Level`：DEBUG / INFO / WARN / ERROR / FATAL
- 时间戳格式化
- 线程 ID 输出
- 文件名和行号输出
- `MINI_LOG_INFO(logger) << "msg" << value` 流式接口
- `SyncLogger` 线程安全写入
- `MemorySink` 用于自动化断言

## 复盘结论

同步日志适合作为最小可用版本和异步 logger 的对照组。先把前端接口和格式稳定下来，再做异步化，能避免后续重构时同时移动太多边界。
