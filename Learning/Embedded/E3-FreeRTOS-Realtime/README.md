# E3 教学：FreeRTOS、同步与实时性

前置：[E2 驱动](../E2-Peripherals-DMA/README.md) 的中断、缓冲与错误合同。目标是把单线程组件接到真实任务／ISR 交互，而不是换一套线程 API 名称。代码未来放在本模块 `practice`，当前没有 RTOS 移植或板上结果。

## L1 调度与时间不是同一个问题

**先理解**：任务可以就绪、运行、阻塞等，调度器选择符合当前策略的就绪任务。优先级、抢占和时间片影响选择，但不自动提供应用截止时间保证。

FreeRTOS 任务优先级数值越大，任务优先级越高；Cortex-M 中断优先级数值通常越小越紧急，两套数字不能混用。实现位数、编码和分组必须对照当前核心与 port。

tick 是内核时间基准，不是任意精度硬件计时。周期任务要考虑累积漂移、阻塞、超期和 TickType 的回绕；简单的“当前值大于到期值”比较未必跨回绕正确。

**独立练习**

1. 画采集、解析与输出任务的状态时间线，区分执行时间、等待时间和端到端响应。
2. 写每个任务的周期／触发事件、优先级、截止时间预算、阻塞条件与超期处理。
3. 比较一种周期等待与相对延时方案的观测差异，记录 tick 频率和测量条件。

**检查点**：高优先级任务一直就绪可能使低优先级任务饥饿，单纯 yield 不等于会让所有低优先级任务运行。

## L2 同步原语按语义选

| 原语 | 适合表达 | 必须检查 |
| --- | --- | --- |
| 队列 | 数据交付与容量 | 复制的是值还是指针；满时、超时与所有权 |
| 任务通知 | 对指定任务的事件／计数等通知 | 当前模式是否合并／覆盖事件，接收者约束 |
| 信号量 | 事件或资源数量 | 不当作普遍拥有优先级继承的锁 |
| 互斥锁 | 有所有者的共享资源保护 | 不在 ISR 阻塞等待；继承、递归与锁顺序 |
| 事件组 | 多个条件的位状态 | 位合并是否会丢失逐次事件语义，ISR API 行为 |
| stream/message buffer | 字节流／消息传递 | 默认单写者、单读者等约束，不能直接当 MPMC 队列 |

优先级继承能减少部分反转，但不能消除死锁、无界临界区、IO 阻塞或所有调度问题。队列里放入指针也不复制底层 payload，所有权必须有独立规则。

**独立练习**：为三段采集链路各选一种交付方式，说明选它而非其他方式的原因；触发队列满、等待超时和多次通知，核对数据与事件数量。

## L3 ISR 与任务的交界

**先理解**：任务 API 与 `FromISR` API 有不同上下文约束。ISR 不能使用无界阻塞方式等待资源，回调里间接调用的库也必须满足上下文要求。

按所选 Cortex-M port 阅读中断优先级、屏蔽方式与可调用 RTOS API 的边界。使用阈值屏蔽的 port 中，不受内核临界区保护的更紧急中断不能随意访问内核对象。不能把一组配置宏或 BASEPRI 方案套到所有核心。

共享环形缓冲要逐步分析谁更新哪些字段，以及 ISR 会在哪些更新点打断任务。`volatile` 不会把多步更新变成原子操作；关中断、临界区、原子操作和队列也有各自作用范围与成本。

**独立练习**

- 从 E2 的最小 ISR 路径通过通知／队列唤醒任务，解释该 port 所需的 ISR 结束调度处理。
- 构造可控的 ISR／任务交错，核对缓冲所有权、数据数量和边界。
- 对不允许调用内核 API 的中断，设计向可处理上下文转交事件的方式，不凭“测试没崩溃”判断合法。

## L4 资源与实时测量

**先理解**：预算既包含任务栈／堆，也包含中断、调度、锁等待、数据排队和 IO。栈水位与失败检测是证据的一部分，不是对全部路径的静态上界证明。

区分任务栈、异常／中断栈、FPU 上下文等开销，实际由核心和 port 决定。优先静态／有界资源，若允许动态分配，记录时机、碎片与失败传播。

使用 GPIO、硬件计时或合适 trace 测响应、执行、等待与周期抖动；先确认 DWT 等工具是否存在，注明插桩和日志开销。观测最大值不是严格 WCET，短测不能宣称硬实时保证。

**独立练习**

1. 注入受控慢输出与更高负载，记录超期、队列峰值和任务栈水位。
2. 构造并定位优先级反转、锁顺序死锁或饥饿之一，保存任务时间线与栈证据。
3. 修复后用相同负载回归，确认数据合同与资源预算没有被优化破坏。

## 阶段验收与回看

- 三段任务链路有真实调度与资源证据，每个任务的触发、优先级、预算与阻塞条件明确。
- ISR API 使用和优先级配置有原始资料依据，数据与所有权可核对。
- 有一次独立排障与回归，至少一种过载／超时场景有明确结果。
- host 测试不能替代以上板上交互，所有尚未执行项保持待验证。

复述检查：区分任务与中断优先级；解释一种同步原语的选择；说明一次反转／死锁的证据；区分观测最大延迟与证明上界。随后进入 [E4](../E4-Data-Acquisition/README.md)。
