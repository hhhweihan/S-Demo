# E2 教学：外设、DMA 与驱动边界

前置：[E1](../E1-Language-Startup/README.md)。目标是建立手册、配置、波形、数据与错误行为的证据链，不是会调用若干 HAL 函数。练习代码未来放在本模块 `practice`，当前没有板级驱动实现。

## L1 手册与引脚先于代码

**先理解**：外设可用依赖供电、电平、时钟、复位、引脚复用与软件状态。GPIO 输出模式、开漏／推挽、上拉与输入阈值是电气约束，不是任意可互换的参数。

定时器周期由真实时钟源、分频和计数模式决定；不能只用 CPU 主频猜测外设计数时钟。输入抖动、外部信号和采样需求也影响处理方式，ISR 忙等不是通用消抖方法。

**独立练习**

1. 为所选板记录时钟、引脚复用、额定电平与连接依据，只连接兼容的低压实验器件。
2. 用 GPIO 和定时器做一个周期信号，把配置计算与逻辑分析仪／示波器结果对应。
3. 改变一个配置变量并解释现象，保留正确与错误配置的对比，不猜寄存器地址。

## L2 UART 从轮询到中断

**先理解**：UART 提供字节收发，不提供应用帧边界。一次中断、一次 DMA 回调或空闲检测都不必然等于一个完整协议帧。

先用轮询确认链路，再增加中断与固定容量缓冲。ISR 应及时处理必要状态，把解析、格式化和慢输出交给后续流程；对帧错误、溢出、超时和丢弃必须有显式计数与恢复策略。

发送完成也有层次：把字节交给 DMA、DMA 结束、UART 最后一个字节完全离开发送器，不是同一时刻。停止、切换接口或复用源缓冲前，要明确等待哪一种完成。

**独立练习**：连续输入、分片／合并、超速、慢接收与发送中停止；将 [E0 帧解析](../../00-Embedded-Start/Frame-Parser-Guide.md) 接入累积层，但补上物理链路需要的同步、校验和恢复合同。

**检查点**：无帧边界假设，无无限阻塞，缓冲满的错误不会被当作成功。

## L3 I2C 与 SPI 至少选一种

| 总线 | 先理解的机制 | 必测现象 |
| --- | --- | --- |
| I2C | 地址、方向、ACK/NACK、重复起始、上拉、时钟拉伸与超时；区分器件地址和库 API 的地址表示 | 设备缺失、错误地址、超时与恢复；不是读到零就算错误 |
| SPI | CPOL/CPHA、时钟、片选、全双工与事务边界；命令／地址／数据以器件手册为准 | 错误模式、片选边界、读写时序、器件状态与超时 |

**独立练习**：选择一个有公开手册的真实器件，完成最小读写、参数限制、错误报告与有限恢复；保存至少一份总线捕获，解释每段信号和对应数据。

共享总线要定义事务与并发访问范围，不能在一次完整器件事务中间任意释放锁，让其他请求改变片选或协议状态。

## L4 驱动是一组状态与合同

**先理解**：初始化、启动、进行中、完成、超时、取消／停止与恢复是不同状态。接口不仅传数据，还必须规定何时可以再次调用、缓冲何时归还、失败留下什么状态。

寄存器可能具有读清除、写 1 清除、只读与保留位等语义。通用读改写不适用于所有寄存器，`volatile` 也不会修正硬件语义错误。HAL 隐藏部分细节，但调用者仍需理解它的状态机、回调与超时保证。

**独立练习**

- 从一条 HAL UART／定时器路径追到寄存器与手册，独立实现一条最小路径，复用 CMSIS／厂商定义。
- 写驱动状态表，特别说明进行中重复启动、超时后回调、停止与重启交错。
- 注入错误后确认有显式结果、资源释放和下一次调用的可用状态，不用无界重试掩盖失败。

## L5 DMA 与缓冲所有权

**先理解**：DMA 是另一访问者。CPU 不能在传输未完成时复用其缓冲；环形 DMA 继续推进时，也可能覆盖尚未消费的数据。

为每块缓冲标出 `空闲 / DMA 持有 / 完成待消费 / CPU 持有` 等状态，说明交接事件、长度、回绕和过载策略。单生产者／消费者的逻辑队列正确，不等于 DMA 生命周期正确。

还要确认 DMA 可访问的内存区域、对齐与长度限制。有 D-cache 的芯片再依据官方规则处理缓存与所有权交接；清理／失效范围涉及 cache line，不能误伤同一 cache line 中其他活动数据。`volatile` 不替代 cache 维护或硬件顺序要求。

**独立练习**：在完成 UART 中断路径后增加 DMA；验证半满／完成、回绕、消费变慢、输入超速、停止与错误恢复。解释 TX/RX 缓冲何时可以访问与重用，记录对应硬件条件。

## 阶段验收与回看

- GPIO／定时器、UART、I2C/SPI 至少一种有真板证据；配置、波形和数据能对应。
- 驱动状态、资源上限、超时、错误与恢复明确，缓冲所有权可解释。
- 至少一次接口故障定位，保留现象、证据、根因与回归。
- host 测试覆盖协议／策略，不能替代寄存器、ISR、DMA 与电气验证。

常见误区：回调就是完整帧；DMA 完成就是线上发送完成；指针进队列就是数据被复制；开中断后 host 环形缓冲自动线程安全。

闭卷复述一次输入超速和一次超时恢复，再进入 [E3](../E3-FreeRTOS-Realtime/README.md)。
