## Day 51（Tue）— CountDownLatch

**预计时间：1 小时**

**任务：**
- [ ] 创建 `concurrent/countdown_latch.h`
- [ ] 实现 `CountDownLatch`：
  ```cpp
  class CountDownLatch {
      std::mutex mtx_;
      std::condition_variable cv_;
      int count_;
  public:
      explicit CountDownLatch(int n) : count_(n) {}
      void count_down();        // --count_，归零时 notify_all
      void wait();              // 等待 count_ == 0
      void wait_for(std::chrono::milliseconds timeout); // 带超时
  };
  ```
- [ ] 测试：主线程等待 5 个子任务全部完成（每个子任务 count_down() 一次）

**完成标志：** 5 个任务全部完成后 wait() 返回，无超时死锁
