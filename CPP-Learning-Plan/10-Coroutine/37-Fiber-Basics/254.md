## Day 254（Tue）— Fiber 类封装

**预计时间：1 小时**

**任务：**
- [x] 封装 Fiber 类：
  ```cpp
  class Fiber {
  public:
      enum State { READY, RUNNING, SUSPENDED, DONE };
      Fiber(function<void()> fn, size_t stack_size = 128 * 1024);
      ~Fiber();
      void resume();   // 切换到这个 Fiber 执行
      void yield();    // 让出执行权，切回调用者
      State state() const;
  private:
      ucontext_t  ctx_;
      ucontext_t* caller_ctx_;  // 调用者上下文（用于 yield 返回）
      unique_ptr<char[]> stack_;
      function<void()> fn_;
      State state_ = READY;
  };
  ```
- [x] 处理 Fiber 正常结束（fn_ 返回后状态变为 DONE，切回 caller）
- [x] 测试：创建 10 个 Fiber，依次 resume

> 口径说明：本仓库落点为跨平台模拟（coroutine_lib C++20 无栈协程 `Task` + 单线程 FIFO 调度，无 `ucontext_t` 栈与上下文切换），本日 [x] 记录的是有栈协程原理与生命周期的概念与设计掌握；真实 `ucontext_t` 有栈协程 Fiber（栈分配 + 上下文切换）的实现属于下一步 Linux 补课，见本模块 README「实现口径」小节（真实 epoll+timerfd 落地参考 raft_kv/net/）。

**完成标志：** Fiber 生命周期管理正确（READY→RUNNING→DONE）
