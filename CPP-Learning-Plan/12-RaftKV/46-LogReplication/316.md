## Day 316（Mon）— 日志结构设计

**预计时间：1 小时**

**任务：**
- [x] 设计 `RaftLog`：
  ```cpp
  struct LogEntry {
      int64_t index;    // 日志下标（从 1 开始）
      int64_t term;     // 产生该条目的 term
      std::string data; // 状态机命令（如 "SET key value"）
  };

  class RaftLog {
      std::vector<LogEntry> entries_;  // entries_[0] 是哨兵（index=0, term=0）
  public:
      int64_t last_index() const;
      int64_t last_term() const;
      LogEntry get(int64_t index) const;
      void append(LogEntry entry);
      void truncate_after(int64_t index);  // 删除 index 之后的所有条目（日志冲突时）
  };
  ```
- [x] 测试：append / get / truncate 基本操作
