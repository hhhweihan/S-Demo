**预计时间：1 小时**

**任务：**

  ```cpp
  template<typename T>
  class Future {
  public:
      T get();                     // 阻塞等待（同步使用）
      void then(function<void(T)> cb);  // 注册回调（异步使用）
      bool ready() const;
  };
  ```
