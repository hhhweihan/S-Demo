**任务：**
- [ ] 实现 RPC 超时（集成 Month 9 定时器）：
  ```cpp
  // 发送请求时同时添加超时定时器：
  timer_id = timer.add(timeout_ms, [id, &pending_]{
      auto it = pending_.find(id);
      if (it != pending_.end()) {
          it->second.set_exception(RpcTimeoutException{});
          pending_.erase(it);
      }
  });
  // 响应到达时取消定时器：
  on_response(id, resp) { timer.cancel(timer_id); ... }
  ```
