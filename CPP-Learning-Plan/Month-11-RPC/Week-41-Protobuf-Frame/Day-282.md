  ┌─────────────┬────────────┬──────────┬─────────────────┐
  │ magic(2B)   │ type(1B)   │ id(4B)   │ payload_len(4B) │
  ├─────────────┴────────────┴──────────┴─────────────────┤

  └─────────────────────────────────────────────────────────┘

  ```

      // 解码：从 Buffer 中提取完整帧（处理粘包）
      static bool decode(Buffer& buf, Frame& frame);
  };
  ```
