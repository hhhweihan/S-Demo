## Day 255（Wed）— 栈保护 + 内存管理

**预计时间：1 小时**

**任务：**
- [x] 实现栈溢出检测（使用 mprotect 在栈底设置不可访问页）：
  ```cpp
  // 分配栈并保护底部
  void* stack = mmap(nullptr, stack_size + PAGE_SIZE,
                     PROT_READ|PROT_WRITE, MAP_PRIVATE|MAP_ANON, -1, 0);
  mprotect(stack, PAGE_SIZE, PROT_NONE);  // 保护底部一页
  ```
- [x] 分析默认栈大小的选择（128KB 是个合理起点）
- [x] 实现 FiberPool：预分配固定数量 Fiber，避免频繁 mmap

**完成标志：** 栈溢出时触发 SIGSEGV，而不是静默损坏数据
