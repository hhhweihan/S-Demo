## Day 159（Fri）— 异步 Sink 包装

**预计时间：1 小时**

**任务：**
- [x] 实现 `AsyncSinkWrapper`：将任何同步 Sink 包装成异步（内部有后台线程和缓冲队列）
  ```cpp
  class AsyncSinkWrapper : public Sink {
      shared_ptr<Sink> inner_;
      BlockingQueue<LogEntry> queue_;
      std::thread worker_;
  public:
      void write(...) override { queue_.push(entry); }  // 非阻塞
  };
  ```
- [x] 这与 Week 22 的 AsyncLogger 不同：这是 Sink 级别的异步，更灵活
- [x] 性能对比：AsyncSinkWrapper vs 直接 AsyncLogger

**完成标志：** AsyncSinkWrapper 包装 FileSink 后性能提升
