## Day 242（Thu）— 后端故障摘除

**预计时间：1 小时**

**任务：**
- [x] 实现熔断机制（Circuit Breaker）：
  - 后端连续失败 5 次 → 标记为不可用（OPEN 状态）
  - OPEN 状态持续 30 秒 → 进入 HALF-OPEN（试探）
  - 试探成功 → 恢复 CLOSED 状态
  ```cpp
  enum class CircuitState { CLOSED, OPEN, HALF_OPEN };
  ```
- [x] 健康检查通过后自动将后端加回负载均衡
- [x] 测试：模拟一个后端宕机，验证流量切走 + 恢复

> 口径说明：本仓库落点为跨平台模拟（high_perf_net 进程内 `ConnectionPool` + RR/LeastConn，熔断器/健康探测未落地为独立组件），本日 [x] 记录的是熔断状态机与故障摘除的概念与设计掌握；面向真实 TCP 后端的健康探测与熔断摘除实现属于下一步 Linux 补课，见本模块 README「实现口径」小节（真实 epoll+timerfd 落地参考 raft_kv/net/）。
