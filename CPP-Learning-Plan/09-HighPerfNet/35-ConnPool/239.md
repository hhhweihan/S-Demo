## Day 239（Mon）— 连接池基础设计

**预计时间：1 小时**

**任务：**
- [x] 设计连接池接口：
  ```cpp
  class TcpConnPool {
  public:
      TcpConnPool(const string& host, int port,
                  int min_size = 4, int max_size = 32);
      // 获取连接（没有空闲则新建，超过 max 则阻塞等待）
      shared_ptr<TcpConn> acquire(int timeout_ms = 1000);
      // 归还连接（正常归还 or 连接异常时销毁）
      void release(shared_ptr<TcpConn> conn, bool healthy = true);
  private:
      deque<shared_ptr<TcpConn>> idle_;
      mutex mu_;
      condition_variable cv_;
      int active_count_ = 0;
  };
  ```
- [x] 实现 `acquire` 和 `release` 基础版（单后端）
- [x] 测试：4 个工作线程共享连接池，并发请求不报错

> 口径说明：本仓库落点为跨平台模拟（high_perf_net 进程内 `ConnectionPool`，后端为进程内 `Backend` 对象，非真实 TCP 连接/握手），本日 [x] 记录的是连接池 acquire/release 的概念与设计掌握；真实 TCP 连接池（socket 握手 + 内核资源复用）的实现属于下一步 Linux 补课，见本模块 README「实现口径」小节（真实 epoll+timerfd 落地参考 raft_kv/net/）。
