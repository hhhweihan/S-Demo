## Day 232（Mon）— io_uring 基础原理

**预计时间：1 小时**

**任务：**
- [x] 理解 io_uring 三个核心：
  ```
  SQ（Submission Queue）：用户态提交 IO 请求
  CQ（Completion Queue）：内核填写完成事件
  SQE/CQE：请求/完成条目（ring buffer，避免系统调用）
  ```
- [x] 安装 liburing（`sudo apt install liburing-dev`）
- [x] 实现 Hello io_uring：
  ```c
  struct io_uring ring;
  io_uring_queue_init(256, &ring, 0);
  // 提交一个 read 请求
  struct io_uring_sqe *sqe = io_uring_get_sqe(&ring);
  io_uring_prep_read(sqe, fd, buf, sizeof(buf), 0);
  io_uring_submit(&ring);
  // 等待完成
  struct io_uring_cqe *cqe;
  io_uring_wait_cqe(&ring, &cqe);
  ```
- [x] 测试：用 io_uring 异步读文件

> 口径说明：本仓库落点为跨平台模拟（IoUringSimulator 用户态 SQ-CQ 环，无 liburing、无真实 io_uring 系统调用），本日 [x] 记录的是 SQ/CQ 概念与设计掌握；真实原生 io_uring（liburing）SQE/CQE 提交与文件异步读的实现属于下一步 Linux 补课，见本模块 README「实现口径」小节（真实 epoll+timerfd 落地参考 raft_kv/net/）。
