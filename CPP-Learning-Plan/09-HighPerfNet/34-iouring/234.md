## Day 234（Wed）— 注册固定缓冲区

**预计时间：1 小时**

**任务：**
- [x] 实现固定缓冲区（减少内核/用户态内存映射开销）：
  ```cpp
  // 预注册缓冲区到内核
  struct iovec iovecs[256];
  // 分配 256 个 4KB 缓冲区
  io_uring_register_buffers(&ring, iovecs, 256);
  // 使用注册缓冲区（不用 io_uring_prep_read，用 io_uring_prep_read_fixed）
  io_uring_prep_read_fixed(sqe, fd, buf, len, offset, buf_index);
  ```
- [x] 对比：有无固定缓冲区的性能差异

> 口径说明：本仓库落点为跨平台模拟（IoUringSimulator 用户态 SQ-CQ 环，无 liburing、无真实 io_uring 系统调用），本日 [x] 记录的是固定缓冲区减少拷贝的概念与设计掌握；真实原生 io_uring 固定缓冲区（`io_uring_register_buffers`/`prep_read_fixed`）的实现属于下一步 Linux 补课，见本模块 README「实现口径」小节（真实 epoll+timerfd 落地参考 raft_kv/net/）。
