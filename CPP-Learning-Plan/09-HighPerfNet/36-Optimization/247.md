## Day 247（Tue）— splice + 管道零拷贝

**预计时间：1 小时**

**任务：**
- [x] 实现 `splice` 管道转发（两个 fd 之间，无需经过用户态）：
  ```cpp
  int pipefd[2];
  pipe(pipefd);
  // 从 src_fd 移动数据到管道（无拷贝）
  splice(src_fd, nullptr, pipefd[1], nullptr, len, SPLICE_F_MOVE);
  // 从管道移动到 dst_fd（无拷贝）
  splice(pipefd[0], nullptr, dst_fd, nullptr, len, SPLICE_F_MOVE);
  ```
- [x] 实现一个 TCP 代理（双向 splice 转发）
- [x] 测试：代理 100MB 数据传输性能

> 口径说明：本仓库落点为跨平台模拟（high_perf_net 未落地 sendfile/splice/SO_REUSEPORT，仅作概念边界分析），本日 [x] 记录的是管道零拷贝原理的概念与设计掌握；真实 `splice` 管道零拷贝与双向 TCP 代理的实现属于下一步 Linux 补课，见本模块 README「实现口径」小节（真实 epoll+timerfd 落地参考 raft_kv/net/）。
