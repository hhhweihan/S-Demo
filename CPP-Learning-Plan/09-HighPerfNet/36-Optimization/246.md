## Day 246（Mon）— 零拷贝 sendfile

**预计时间：1 小时**

**任务：**
- [x] 实现基于 `sendfile(2)` 的文件传输（内核直接传输，不经用户态）：
  ```cpp
  // 普通方式（两次拷贝）：
  // disk → kernel buffer → user buffer → kernel socket buffer → NIC
  // sendfile 方式（一次拷贝）：
  // disk → kernel buffer → kernel socket buffer → NIC
  ssize_t ret = sendfile(sock_fd, file_fd, &offset, file_size);
  ```
- [x] 对比：100MB 文件，read/write vs sendfile 耗时和 CPU 使用率

> 口径说明：本仓库落点为跨平台模拟（high_perf_net 未落地 sendfile/splice/SO_REUSEPORT，仅作概念边界分析），本日 [x] 记录的是零拷贝原理的概念与设计掌握；真实 `sendfile(2)` 零拷贝文件传输的实现属于下一步 Linux 补课，见本模块 README「实现口径」小节（真实 epoll+timerfd 落地参考 raft_kv/net/）。

**完成标志：** sendfile 比 read/write 快，CPU 使用率更低
