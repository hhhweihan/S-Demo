## Day 72（Tue）— 手写 variant（存储部分）

**预计时间：1 小时**

**任务：**
- [x] 实现 `Variant<Ts...>` 的存储：
  ```cpp
  template<typename... Ts>
  class Variant {
      // 用 union 或 aligned_storage 存储最大的类型
      static constexpr size_t SIZE  = max_size<Ts...>();   // 编译期求最大 sizeof
      static constexpr size_t ALIGN = max_align<Ts...>();  // 编译期求最大 alignof
      alignas(ALIGN) char storage_[SIZE];
      size_t index_ = variant_npos;  // 当前存的是第几个类型

      template<size_t I, typename... Us> struct GetType;  // 辅助：index -> type
  };
  ```
- [x] 实现构造：`Variant<int, std::string> v("hello")` 识别类型，in-place 构造

**完成标志：** 构造 Variant 后 index() 返回正确的类型下标

## 本日结论

- `Variant<Ts...>` 的存储需要满足所有候选类型里的最大 size 和最大 alignment
- `index_` 是运行时分发的核心状态，`variant_npos` 表示当前无值
- 构造时通过 `index_of<T, Ts...>` 把类型映射为下标
