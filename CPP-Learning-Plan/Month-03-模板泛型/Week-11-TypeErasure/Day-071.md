## Day 71（Mon）— 手写 optional

**预计时间：1 小时**

**任务：**
- [ ] 创建 `templates/my_optional.h`
- [ ] 实现 `Optional<T>`：
  ```cpp
  template<typename T>
  class Optional {
      alignas(T) char storage_[sizeof(T)];  // 对齐存储，不提前构造
      bool has_value_ = false;
  public:
      Optional() = default;
      Optional(T val) : has_value_(true) { new(storage_) T(std::move(val)); }
      ~Optional() { if (has_value_) reinterpret_cast<T*>(storage_)->~T(); }
      // 拷贝/移动构造、赋值...
      bool has_value() const { return has_value_; }
      T& value();                      // 无值时抛 std::bad_optional_access
      T value_or(T default_val) const;
      explicit operator bool() const { return has_value_; }
  };
  ```
- [ ] 测试：Optional<std::string> 无值 / 有值 / value_or

**完成标志：** 无值时 value() 抛异常，有值时正确返回
