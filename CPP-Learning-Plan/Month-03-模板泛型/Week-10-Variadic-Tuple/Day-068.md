**预计时间：1 小时**

**任务：**
- [x] 实现 `apply(f, tuple)`（把 tuple 展开为函数参数）：
  ```cpp
  template<typename F, typename Tuple, size_t... Is>
  auto apply_impl(F&& f, Tuple&& t, std::index_sequence<Is...>) {
      return f(get<Is>(std::forward<Tuple>(t))...);
  }
  template<typename F, typename... Ts>
  auto apply(F&& f, Tuple<Ts...>& t) {
      return apply_impl(f, t, std::make_index_sequence<sizeof...(Ts)>{});
  }
  ```
- [x] 实现 `operator==`（逐元素比较）
- [x] 实现 `print(tuple)`：打印 `(1, 2.0, "hello")`
- [x] 测试：`apply([](int a, double b){ return a + b; }, t)` 返回 3.0

## 本日结论

- `apply` 是 `index_sequence` 和 `get<Is>(tuple)...` 的组合
- `operator==` 可以用 `((get<Is>(lhs) == get<Is>(rhs)) && ...)` 做逐元素比较
- `print(tuple)` 的难点不是输出本身，而是处理分隔符和空参数包边界
