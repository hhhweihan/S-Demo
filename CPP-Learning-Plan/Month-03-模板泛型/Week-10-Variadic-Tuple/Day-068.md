- [ ] 实现 `apply(f, tuple)`（把 tuple 展开为函数参数）：
  ```cpp
  template<typename F, typename Tuple, size_t... Is>
  auto apply_impl(F&& f, Tuple&& t, std::index_sequence<Is...>) {
      return f(get<Is>(std::forward<Tuple>(t))...);
  }
  template<typename F, typename... Ts>
  auto apply(F&& f, Tuple<Ts...>& t) {
      return apply_impl(f, t, std::make_index_sequence<sizeof...(Ts)>{});
  }
  ```
