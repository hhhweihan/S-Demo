## Day 64（Mon）— 变参模板基础

**预计时间：1 小时**

**任务：**
- [x] 写 5 个变参模板函数练习：
  ```cpp
  // 1. 求所有参数之和
  template<typename... Args>
  auto sum(Args... args) { return (args + ...); }  // 折叠表达式

  // 2. 打印所有参数（用逗号分隔）
  template<typename... Args>
  void print_all(Args&&... args) {
      ((std::cout << args << " "), ...);
  }

  // 3. 统计参数个数
  template<typename... Args>
  constexpr size_t count() { return sizeof...(Args); }

  // 4. 检查是否所有参数都是整数
  template<typename... Args>
  constexpr bool all_integral = (std::is_integral_v<Args> && ...);

  // 5. 找出第 N 个类型
  template<size_t N, typename... Args>
  using nth_type = std::tuple_element_t<N, std::tuple<Args...>>;  // 先用标准库
  ```

**完成标志：** 5 个都能正确编译运行

## 实践落点

- 代码目录：`CPP-Practice/variadic_tuple/`
- 入口文件：`CPP-Practice/variadic_tuple/main.cpp`
- 覆盖函数：`sum`、`print_all`、`count`、`all_integral`、`nth_type`

## 本日结论

- `sizeof...(Args)` 是参数包大小查询的基础工具
- 折叠表达式适合把“对每个参数做同一件事”压成一行
- `std::tuple_element_t<N, std::tuple<Args...>>` 是学习自写 `TupleElement` 前最直接的标准库参照
