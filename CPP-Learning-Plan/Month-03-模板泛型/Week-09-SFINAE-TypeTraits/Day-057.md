## 任务

- [x] 复习：函数模板 vs 函数重载的优先级规则
- [x] 写 3 个例子，区分「模板特化」和「函数重载」的行为差异
- [x] 理解 ADL（Argument-Dependent Lookup）：

  ```cpp
  namespace ns { struct Foo {}; void swap(Foo&, Foo&); }
  // 为什么 std::swap 会调用 ns::swap？
  ```

- [x] 实现 `is_same<T, U>`（最简版）：

  ```cpp
  template<typename T, typename U> struct is_same : std::false_type {};
  template<typename T>             struct is_same<T, T> : std::true_type {};
  ```

## 完成标志

## 本日结论

- 普通函数重载和函数模板同时可行时，优先选择普通函数重载
- 显式特化不是独立重载集成员；先完成模板重载决议，再看主模板是否存在匹配特化
- 自定义类型想让交换走更优实现时，常用写法是 `using std::swap; swap(a, b);`，由 ADL 把同命名空间下的 `swap` 找出来
