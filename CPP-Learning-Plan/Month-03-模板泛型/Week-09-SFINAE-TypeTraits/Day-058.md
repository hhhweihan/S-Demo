## Day 58（Tue）— SFINAE 入门

**预计时间：1 小时**

**任务：**
- [x] 理解 SFINAE 的含义：Substitution Failure Is Not An Error
- [x] 写 3 个例子演示 SFINAE：
  ```cpp
  // 例 1：只对有 .size() 方法的类型生效
  template<typename T>
  auto print_size(T t) -> decltype(t.size(), void()) {
      std::cout << t.size();
  }
  // 对 int 调用：SFINAE，编译期不报错，只是找不到这个重载

  // 例 2：用 void_t 检测成员
  template<typename T, typename = void>
  struct has_value_type : std::false_type {};
  template<typename T>
  struct has_value_type<T, std::void_t<typename T::value_type>> : std::true_type {};
  ```
- [x] 手写 `has_iterator<T>`：检测 T 是否有 `begin()` 方法

**完成标志：** `has_iterator<std::vector<int>>::value == true`，`has_iterator<int>::value == false`

## 本日结论

- SFINAE 发生在模板参数替换阶段：替换失败不会立刻变成硬编译错误，而是把该候选模板从重载集中移除
- `decltype(expr, void())` 适合快速检测表达式是否成立
- `void_t` 可以把“某个类型/表达式是否存在”的问题转换成偏特化选择问题
