## Day 195（Sat）— 用 LevelDB 写应用

**预计时间：2 小时**

**任务：**
- [x] 用 LevelDB 实现一个「配置中心」小工具：
  - `set key value`：存储配置
  - `get key`：读取配置
  - `delete key`：删除配置
  - `list prefix`：列出所有以 prefix 开头的 key
  - 数据持久化：重启后配置不丢失
- [x] 用你的工具实际存储 50 条配置，重启程序后验证数据完整

**完成标志：** 工具功能完整，重启后数据不丢失
