## Day 52（Wed）— 整合到线程池

**预计时间：1 小时**

**任务：**
- [x] 用 `CountDownLatch` 实现线程池的 `await_termination()`：
  ```cpp
  // 提交任务时：latch_.count_up()（注意：需要把 CountDownLatch 改成支持递增）
  // 任务完成时：latch_.count_down()
  // await_termination()：latch_.wait()
  ```
  或者用 `std::atomic<int> pending_tasks_` + condition_variable 实现
- [x] 给线程池加 `pause()` / `resume()`（暂停/恢复接受新任务）
- [x] 测试：提交 100 个慢任务，pause，再提交 100 个任务（应该阻塞），resume 后继续

**实现位置：**

- [CPP-Practice/thread_pool/concurrent/thread_pool.h](../../../CPP-Practice/thread_pool/concurrent/thread_pool.h)
- [CPP-Practice/thread_pool/main.cpp](../../../CPP-Practice/thread_pool/main.cpp)

**结果记录：**

- `await_termination()` 已切换为 `CountDownLatch` 驱动，任务提交时 `count_up()`，任务执行完成时 `count_down()`
- `pause()` 会阻塞后续 `submit()`，但不会中断已经入队或正在执行的任务
- `resume()` 通过条件变量统一唤醒等待中的提交线程
- `test_day52_pause_resume_and_await_termination()` 已验证暂停期间第二批 100 个任务确实卡住，恢复后 200 个任务全部完成

**完成标志：** `pause/resume` 逻辑正确，`await_termination()` 能等待所有任务完成
