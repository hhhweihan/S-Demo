## Day 155（Mon）— Sink 抽象接口

**预计时间：1 小时**

**任务：**
- [x] 定义 Sink 抽象基类：
  ```cpp
  class Sink {
  public:
      virtual ~Sink() = default;
      virtual void write(LogLevel lv, const char* data, size_t len) = 0;
      virtual void flush() = 0;
  };
  ```
- [x] 重构 Logger：持有 `vector<shared_ptr<Sink>>` 代替直接写文件
- [x] 实现 `Logger::add_sink(sink)` / `Logger::remove_sink(id)` 热插拔
- [x] 测试：同时注册两个 sink，验证都收到日志

**完成标志：** Logger 可以同时输出到多个目标
