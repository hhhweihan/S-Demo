# Week 17 — 红黑树 from scratch

## 本周目标

从零实现红黑树，理解 5 条性质如何保证 O(log n) 的高度约束。

---

## Day 1（Mon）— 红黑树性质 + 节点设计

**预计时间：1 小时**

**任务：**
- [ ] 理解并背诵 5 条红黑树性质：
  1. 每个节点是红色或黑色
  2. 根节点是黑色
  3. 所有叶子（NIL 节点）是黑色
  4. 红色节点的两个子节点都是黑色（不能有连续红节点）
  5. 从任一节点到其叶子的所有路径，黑色节点数相同（黑高一致）
- [ ] 定义节点：
  ```cpp
  enum Color { RED, BLACK };
  template<typename Key, typename Value>
  struct RBNode {
      Key    key;
      Value  val;
      Color  color = RED;
      RBNode *left = nullptr, *right = nullptr, *parent = nullptr;
  };
  ```
- [ ] 实现 `left_rotate(x)` 和 `right_rotate(x)`（画图后再写代码）

**完成标志：** 旋转后父子关系更新正确（手工验证 3-节点案例）

## Day 2（Tue）— insert + 修复

**预计时间：1 小时**

**任务：**
- [ ] 实现 `insert(key, val)`：先按 BST 规则插入（新节点为红色），再修复
- [ ] 插入修复 `insert_fixup(z)` 的 3 种情况：
  ```
  情况 1：叔父节点为红 → 变色（父+叔 变黑，祖父变红，z 上移两层）
  情况 2：叔父为黑，z 是父的右孩子 → 左旋，转为情况 3
  情况 3：叔父为黑，z 是父的左孩子 → 父变黑，祖父变红，右旋祖父
  ```
- [ ] 测试：插入 1-7，验证树形符合红黑树性质

**完成标志：** 插入 7 个有序数字后树仍满足 5 条性质

## Day 3（Wed）— delete + 修复

**预计时间：1 小时**

**任务：**
- [ ] 实现 `erase(key)`：找到节点 → 用后继替换 → 修复
- [ ] `delete_fixup(x)` 的 4 种情况（黑色亏欠修复）：
  ```
  情况 1：兄弟为红 → 兄弟变黑，父变红，旋转父，转为情况 2/3/4
  情况 2：兄弟为黑，兄弟两子都黑 → 兄弟变红，亏欠上移
  情况 3：兄弟为黑，兄弟左红右黑 → 右旋兄弟，转为情况 4
  ```

**完成标志：** 删除后树仍满足红黑树性质，最终为空
