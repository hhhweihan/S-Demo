## Day 331（Tue）— 实现日志压缩

**预计时间：1 小时**

**任务：**
- [ ] `RaftNode::take_snapshot()`：
  ```cpp
  void take_snapshot() {
      auto snap_data = state_machine_->snapshot();
      Snapshot snap{last_applied_, log_.get(last_applied_).term, snap_data};
      // 持久化快照到磁盘
      save_snapshot(snap);
      // 删除 last_applied_ 之前的日志（保留 last_applied_ 作为哨兵）
      log_.compact_before(last_applied_);
  }
  ```
- [ ] 重启时：如果有快照，先 `restore(snapshot)`，再 apply 快照后的日志

**完成标志：** 快照能正确保存和恢复
