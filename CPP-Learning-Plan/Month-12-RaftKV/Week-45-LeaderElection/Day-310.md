## Day 310（Tue）— 选举超时计时器

**预计时间：1 小时**

**任务：**
- [x] 实现 `ElectionTimer` 的模拟验收逻辑：
  ```cpp
  class ElectionTimer {
      EventLoop* loop_;
      int timeout_ms_;    // 随机：150-300ms
      TimerId timer_id_;
      std::function<void()> timeout_cb_;
  public:
      void reset();       // 重置（收到心跳时调用）
      void start();
      void stop();
  };
  ```
- [x] 选举超时是随机的（150-300ms），避免所有节点同时超时
- [x] 测试：固定随机种子生成 3 个 timeout，并由最早超时节点触发选举

**完成标志：** 模拟 timeout 落在 150-300ms，且 timeout winner 能成为 Leader；真实 EventLoop 计时器不作为学习 demo 验收要求
