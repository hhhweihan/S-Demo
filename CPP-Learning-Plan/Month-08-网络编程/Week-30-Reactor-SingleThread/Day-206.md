## Day 206（Wed）— 实现 Channel + EventLoop

**预计时间：1 小时**

**任务：**
- [ ] `Channel`：
  ```cpp
  class Channel {
      int fd_;
      uint32_t events_ = 0;     // 关心的事件（EPOLLIN | EPOLLOUT）
      uint32_t revents_ = 0;    // epoll 返回的实际事件
      std::function<void()> read_cb_, write_cb_, close_cb_;
  public:
      void handle_event();  // 根据 revents_ 调用对应回调
      void enable_reading();
      void enable_writing();
  };
  ```
- [ ] `EventLoop`：
  ```cpp
  class EventLoop {
      std::unique_ptr<Poller> poller_;
      bool running_ = true;
  public:
      void loop();  // while(running_) { 活跃ch = poller_.poll(); 逐个 handle_event(); }
      void quit();
  };
  ```

**完成标志：** EventLoop::loop() 能持续运行并分发事件
