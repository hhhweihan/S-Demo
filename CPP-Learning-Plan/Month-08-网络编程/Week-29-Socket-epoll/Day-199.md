## Day 199（Wed）— 非阻塞 Socket + fcntl

**预计时间：1 小时**

**任务：**
- [ ] 用 `fcntl(fd, F_SETFL, O_NONBLOCK)` 把 socket 设为非阻塞
- [ ] 理解非阻塞 read/write 的返回值：
  - `> 0`：读/写了 n 字节
  - `== 0`：连接关闭
  - `== -1 && errno == EAGAIN`：暂无数据，稍后重试
  - `== -1 && errno == EINTR`：被信号中断，重试
