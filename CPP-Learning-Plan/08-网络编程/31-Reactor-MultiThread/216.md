## Day 216（Sat）— 定时器实现

**预计时间：2 小时**

**任务：**
- [x] 用 `timerfd_create` 实现定时器（纯 fd 风格，可集成进 epoll）：
  - `run_after(delay, callback)`：N 毫秒后执行一次
  - `run_every(interval, callback)`：每 N 毫秒重复执行
- [x] 集成进 EventLoop：定时器触发时作为普通 epoll 事件处理

> 口径说明：本仓库落点为跨平台模拟（network_reactor 便携 Reactor 核，内存事件分发而非真实 fd 事件），本日 [x] 记录的是定时器集成进事件循环的概念与设计掌握；真实 `timerfd_create` 定时器并作为普通 epoll 事件处理的原生实现属于下一步 Linux 补课，见本模块 README「实现口径」小节（真实 epoll+timerfd 落地参考 raft_kv/net/）。

**完成标志：** 定时器能精确触发（误差 < 10ms）
