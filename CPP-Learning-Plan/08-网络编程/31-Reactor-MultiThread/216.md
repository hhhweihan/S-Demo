## Day 216（Sat）— 定时器实现

**预计时间：2 小时**

**任务：**
- [x] 用 `timerfd_create` 实现定时器（纯 fd 风格，可集成进 epoll）：
  - `run_after(delay, callback)`：N 毫秒后执行一次
  - `run_every(interval, callback)`：每 N 毫秒重复执行
- [x] 集成进 EventLoop：定时器触发时作为普通 epoll 事件处理

**完成标志：** 定时器能精确触发（误差 < 10ms）
