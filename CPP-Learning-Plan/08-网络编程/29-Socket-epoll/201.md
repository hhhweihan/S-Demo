## Day 201（Fri）— epoll LT 模式

**预计时间：1 小时**

**任务：**
- [x] 用 `epoll_create1` + `epoll_ctl` + `epoll_wait` 实现 Echo Server
  ```cpp
  int epfd = epoll_create1(0);
  // 注册 listen_fd 的 EPOLLIN 事件
  struct epoll_event ev{.events = EPOLLIN, .data.fd = listen_fd};
  epoll_ctl(epfd, EPOLL_CTL_ADD, listen_fd, &ev);
  // 事件循环
  while(true) {
      int n = epoll_wait(epfd, events, MAX_EVENTS, -1);
      for (int i = 0; i < n; i++) {
          if (events[i].data.fd == listen_fd) { /* accept */ }
          else { /* read/write */ }
      }
  }
  ```
- [x] LT（水平触发）：fd 有数据就一直通知，直到读完

> 口径说明：本仓库落点为跨平台模拟（network_reactor 便携 Reactor 核，内存事件分发而非真实 `epoll_wait`），本日 [x] 记录的是概念与设计掌握；真实 `epoll_create1`/`epoll_ctl`/`epoll_wait` 的 LT echo server 的原生实现属于下一步 Linux 补课，见本模块 README「实现口径」小节（真实 epoll+timerfd 落地参考 raft_kv/net/）。
