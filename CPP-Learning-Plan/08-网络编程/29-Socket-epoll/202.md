**任务：**
- [x] 理解 ET（边缘触发）：只在状态变化时通知一次，必须一次读完所有数据
  ```cpp
  // ET 模式必须循环读，直到 EAGAIN
  while (true) {
      ssize_t n = read(fd, buf, sizeof(buf));
      if (n < 0 && errno == EAGAIN) break;  // 读完了
      if (n <= 0) { close(fd); break; }      // 错误或关闭
      // 处理数据
  }
  ```
