## Day 199（Wed）— 非阻塞 Socket + fcntl

**预计时间：1 小时**

**任务：**
- [x] 用 `fcntl(fd, F_SETFL, O_NONBLOCK)` 把 socket 设为非阻塞
- [x] 理解非阻塞 read/write 的返回值：
  - `> 0`：读/写了 n 字节
  - `== 0`：连接关闭
  - `== -1 && errno == EAGAIN`：暂无数据，稍后重试
  - `== -1 && errno == EINTR`：被信号中断，重试
- [x] 实现非阻塞 Echo Server（用忙等 EAGAIN 实现，下一步改成 epoll）

> 口径说明：本仓库落点为跨平台模拟（network_reactor 便携 Reactor 核，内存事件分发而非真实 POSIX socket），本日 [x] 记录的是概念与设计掌握；真实 `fcntl(O_NONBLOCK)` 非阻塞 socket 与 EAGAIN echo server 的原生实现属于下一步 Linux 补课，见本模块 README「实现口径」小节（真实 epoll+timerfd 落地参考 raft_kv/net/）。

**完成标志：** 非阻塞 server 能正确处理 EAGAIN
