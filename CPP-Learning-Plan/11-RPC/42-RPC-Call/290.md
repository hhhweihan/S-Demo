## Day 290（Wed）— 超时与取消

**预计时间：1 小时**

**任务：**
- [x] 实现 RPC 超时（集成 Month 9 定时器）：
  ```cpp
  // 发送请求时同时添加超时定时器：
  timer_id = timer.add(timeout_ms, [id, &pending_]{
      auto it = pending_.find(id);
      if (it != pending_.end()) {
          it->second.set_exception(RpcTimeoutException{});
          pending_.erase(it);
      }
  });
  // 响应到达时取消定时器：
  on_response(id, resp) { timer.cancel(timer_id); ... }
  ```
- [x] 实现 `cancel(request_id)` → 取消还未发出的请求或放弃等待
- [x] 测试：服务端故意延迟 2 秒，客户端 1 秒超时触发

**完成标志：** 超时正确触发，无资源泄漏（pending_ map 清理）
