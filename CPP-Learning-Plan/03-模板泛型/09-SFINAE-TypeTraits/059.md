**预计时间：1 小时**

**任务：**
- [x] 手写 `enable_if`：
  ```cpp
  template<bool B, typename T = void>
  struct enable_if {};
  template<typename T>
  struct enable_if<true, T> { using type = T; };
  ```
- [x] 用 `enable_if` 限制模板：
  ```cpp
  // 只有 T 是整数类型时才能调用
  template<typename T>
  typename std::enable_if<std::is_integral<T>::value, T>::type
  double_it(T x) { return x * 2; }
  ```
- [x] 用 C++17 `if constexpr` 重写同样的逻辑，对比代码量

## 本日结论

- `enable_if<false, T>` 不提供 `type`，放在函数签名里可以让候选模板在替换阶段被移除
- `if constexpr` 更适合函数体内部按类型分支，代码可读性通常比把条件塞进返回类型更好
- 对“某个调用是否能编译”的验证不要真的写失败调用，可用检测 trait 验证候选是否存在
