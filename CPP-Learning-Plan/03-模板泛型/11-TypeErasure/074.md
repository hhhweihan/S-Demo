**任务：**

- [x] 实现 `Function<Ret(Args...)>` 用虚函数实现类型擦除：
  ```cpp
  template<typename Ret, typename... Args>
  class Function<Ret(Args...)> {
      struct Base {
          virtual Ret invoke(Args...) = 0;
          virtual ~Base() = default;
      };
      template<typename F>
      struct Derived : Base {
          F func_;
          Derived(F f) : func_(std::move(f)) {}
          Ret invoke(Args... args) override { return func_(args...); }
      };
      std::unique_ptr<Base> ptr_;
  public:
      template<typename F>
      Function(F f) : ptr_(std::make_unique<Derived<F>>(std::move(f))) {}
      Ret operator()(Args... args) { return ptr_->invoke(args...); }
  };
  ```
- [x] 测试：存 lambda / 函数指针 / 带状态的 lambda，都能正确调用

**完成标志：** 三种可调用对象都能存储和调用

## 本日结论

- `Function<Ret(Args...)>` 用虚基类表达统一调用接口，用派生模板保存真实 callable
- `clone()` 是让类型擦除对象支持拷贝的关键
- 空函数调用应抛 `std::bad_function_call`，行为更接近 `std::function`
