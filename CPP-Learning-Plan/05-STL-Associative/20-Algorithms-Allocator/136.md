**预计时间：1 小时**

**任务：**
- [x] 实现以下算法（均基于 lower_bound）：
  ```cpp
  lower_bound(first, last, val)   // 第一个 >= val 的位置
  upper_bound(first, last, val)   // 第一个 > val 的位置
  binary_search(first, last, val) // 是否存在
  equal_range(first, last, val)   // {lower_bound, upper_bound}
  ```
