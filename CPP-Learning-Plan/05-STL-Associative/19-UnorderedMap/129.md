- [x] 实现前向迭代器（遍历所有桶的所有节点）：
  ```cpp
  struct iterator {
      Node*   cur_;    // 当前节点
      size_t  bucket_; // 当前桶索引
      HashTable* ht_;  // 回指哈希表（跨桶时需要跳到下一个非空桶）
      iterator& operator++() {
          cur_ = cur_->next;
          if (!cur_) advance_bucket();  // 跳到下一个非空桶
          return *this;
      }
  };
  ```
