## Day 16（Tue）— 手写 shared_ptr

**预计时间：1 小时**

**任务：**
- [ ] 创建 `smart_ptr/shared_ptr.h`
- [ ] 设计控制块：
  ```cpp
  struct ControlBlock {
      std::atomic<int> use_count{1};
      std::atomic<int> weak_count{0};
      virtual void destroy() = 0;    // 销毁被管理对象
      virtual ~ControlBlock() = default;
  };
  template<typename T>
  struct ControlBlockImpl : ControlBlock {
      T object;
      template<typename... Args>
      ControlBlockImpl(Args&&... args) : object(std::forward<Args>(args)...) {}
      void destroy() override { /* object 在此析构 */ }
  };
  ```
- [ ] 实现 `SharedPtr<T>`：
  - 拷贝构造：`++use_count`
  - 析构：`--use_count`，归零时调用 `destroy()` 并 `delete` 控制块（如果 `weak_count==0`）
  - 移动构造/赋值：转移控制块指针，不修改计数
- [ ] 测试：3 个 SharedPtr 指向同一对象，析构两个后对象仍存在，第三个析构后对象销毁

**完成标志：** 引用计数正确，最后一个 shared_ptr 析构时对象销毁
