## Day 106（Mon）— stack + queue

**预计时间：1 小时**

**任务：**
- [x] 实现 `stack<T, Container = MyDeque<T>>`（容器适配器，不是独立容器）：
  ```cpp
  template<typename T, typename Container = deque<T>>
  class stack {
      Container c_;
  public:
      void push(const T& v) { c_.push_back(v); }
      void pop()            { c_.pop_back(); }
      T&   top()            { return c_.back(); }
      bool empty() const    { return c_.empty(); }
      size_t size() const   { return c_.size(); }
  };
  ```
- [x] 同理实现 `queue<T, Container = MyDeque<T>>`（push_back / pop_front）
- [x] 测试：括号匹配算法（用 stack），BFS（用 queue）
