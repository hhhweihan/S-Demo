## CPP-Learning-Plan — C++ 十二个月进阶计划

这是一个持续推进的 C++ 系统化学习计划。最初用于校招准备，当前则结合实际工作中的关注点继续迭代；在执行过程中，会借助 AI 进行知识点梳理、问题讨论、方案比较、阶段复盘与学习路径细化。

学习节奏为工作日 1 小时 / 周末 2 小时，共 48 周 336 个日任务。

| 月份 | 主题 | 周次 |
| ------ | ------ | ------ |
| Month 01 | 内存管理（内存池 + 智能指针） | Week 01–04 |
| Month 02 | 并发编程（线程池 + 无锁队列） | Week 05–08 |
| Month 03 | 模板泛型（tuple / variant / type_erasure） | Week 09–12 |
| Month 04 | 自编 STL 序列容器（vector / deque / list） | Week 13–16 |
| Month 05 | 自编 STL 关联容器（红黑树 / map / unordered_map） | Week 17–20 |
| Month 06 | 异步日志系统（双缓冲 + 多 Sink） | Week 21–24 |
| Month 07 | LevelDB 源码精读（SkipList + SSTable + Compaction） | Week 25–28 |
| Month 08 | 网络编程（Reactor + HTTP Server） | Week 29–32 |
| Month 09 | 高性能网络库（io_uring + 定时器轮 + 连接池） | Week 33–36 |
| Month 10 | 协程库（ucontext Fiber + 调度器 + Channel） | Week 37–40 |
| Month 11 | RPC 框架（protobuf + 服务发现） | Week 41–44 |
| Month 12 | Mini Raft KV（选举 + 日志复制 + 快照） | Week 45–48 |
